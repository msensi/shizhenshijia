# 是真是假 · 运行与部署说明

> 当前目标：先完成本地验收，再部署到魔搭创空间 Docker

## 运行结构

本项目使用一个 Docker 容器同时提供手机端页面和后端接口：

```text
用户浏览器
   ↓
React 手机端页面
   ↓
FastAPI 核验服务
   ├─ 千问视觉与文本模型
   ├─ 百炼权威证据知识库
   ├─ 千问内置联网搜索（3～5 个权威来源路由）
   └─ SQLite 结构化使用记录
```

模型、知识库和搜索均通过阿里云接口调用，容器只需要 CPU。比赛演示不需要另购阿里云服务器、域名或对象存储。

## 本地运行

准备 Python 3.12 和 Node.js 22，然后执行：

```bash
cp backend/.env.example backend/.env
# 编辑 backend/.env，填写下文列出的 Secret 和普通配置

python3.12 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt

cd frontend && npm ci && cd ..
bash scripts/dev-up.sh
```

浏览器访问 `http://127.0.0.1:5173`。停止服务执行 `bash scripts/dev-down.sh`。

本地验收命令：

```bash
backend/.venv/bin/pytest -q
cd frontend && npm run build
```

## 部署到魔搭创空间

项目根目录已经包含可用的 `Dockerfile`，创空间选择 Docker 类型即可。

1. 将项目代码同步到创空间
2. 在创空间的 Secret 中填写四个密钥
3. 在普通环境变量中填写上面的配置
4. 使用平台 CPU 资源构建并启动
5. 等待健康检查通过，打开公开链接完成手机端验收

容器监听 `7860` 端口。`/mnt/workspace/shizhenshijia/szsj.db` 保存文字化的使用记录，容器不会把用户图片写入该目录。

## 图片隐私

- 浏览器只在内存中保留本次选择的图片，用于处理中页和结果页缩略图；返回首页、选择下一张图或关闭页面时清除
- 后端在内存中完成图片校验与模型调用
- 核验完成后释放图片字节，不写本地磁盘、数据库或对象存储
- 后台只保存核验对象、分类、结论、风险提示、来源、耗时和错误码
- 上传日志不记录用户原始文件名

部署前确认 `KEEP_ORIGINAL_IMAGE=false`、`IMAGE_RETENTION_DAYS=0`。

## 常见问题

### 页面能打开，核验失败

先检查百炼 Key、知识检索服务 ID 和账户额度。不要把 Key 粘贴到聊天或日志中。

### SQLite 数据库报锁

项目已经启用 WAL 和等待重试。比赛规模使用单容器即可，不要同时启动多个写入同一 SQLite 文件的容器副本。

### 魔搭重启后后台记录是否还在

数据库放在 `/mnt/workspace` 持久化目录时会保留；如果平台未为该目录提供持久化，重启后会清空。该情况不影响核验功能，只影响后台历史记录。

### 是否需要对象存储

不需要。产品已确定不保存用户图片，对象存储不会进入当前部署链路。
